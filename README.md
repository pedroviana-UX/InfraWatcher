# 🖥️ InfraWatch

InfraWatch é um projeto pessoal desenvolvido em Python com o objetivo de simular um sistema de monitoramento de infraestrutura, inspirado em ferramentas utilizadas em ambientes NOC.

O projeto está sendo desenvolvido gradualmente como forma de estudo de Python, automação, QA e conceitos de DevOps.

## 🚀 Objetivos

- Aprender Python na prática
- Desenvolver boas práticas de programação
- Simular funcionalidades encontradas em ferramentas de monitoramento
- Construir um portfólio para vagas de QA e DevOps

## 📋 Funcionalidades atuais

- ✅ Menu interativo
- ✅ Cadastro de host
- ✅ Estrutura inicial do projeto
- 🚧 Teste de Ping (em desenvolvimento)
- 🚧 Monitoramento SNMP
- 🚧 Verificação de memória

## 🛠️ Tecnologias
